# 🎀 헬로키티의 달콤한 주방 (Hello Kitty's Sweet Kitchen)

산리오의 사랑스러운 캐릭터들과 함께하는 2D 웹 요리 타이쿤 게임입니다.
별도의 서버나 빌드 도구 없이 웹 브라우저에서 즉시 실행할 수 있습니다.

---

## 🎮 게임 실행 방법

1. `hellokitty-cooking-game` 폴더의 [index.html](file:///d:/김예진/12_UI제작/hellokitty-cooking-game/index.html) 파일을 웹 브라우저로 엽니다.
2. 메인 화면에서 **「💖 게임 시작하기 💖」** 버튼을 클릭하여 60초 요리 챌린지를 시작합니다.

---

## 🍳 다채로운 8종 요리 레시피 (매 판 랜덤 주문!)

총 8가지의 다양한 요리 중 매 라운드마다 3가지 요리가 **무작위(랜덤)**로 주문됩니다.
게임 화면 상단의 **[📖 레시피북]** 아이콘을 누르면 언제든지 레시피를 확인할 수 있습니다.

| 요리 이름 | 분류 | 필요 재료 | 조리 시간 | 특징 |
| :--- | :---: | :--- | :---: | :--- |
| **🍜 계란 라면** | 식사 | `면` + `계란` + `물` | 5초 | 깊고 구수한 국물에 고소한 계란 |
| **🧀🍜 치즈 라면** | 식사 | `면` + `물` + `치즈` | 4초 | 슬라이스 치즈가 사르르 녹아내리는 라면 |
| **🍳 계란 프라이** | 브런치 | `계란` + `기름` | 3초 | 노릇노릇 하트 계란 프라이 |
| **🥪 치즈 샌드위치** | 브런치 | `빵` + `치즈` | 4초 | 겉바속촉 고소한 토스트 샌드위치 |
| **🍞 프렌치 토스트** | 브런치 | `빵` + `계란` + `우유` | 4초 | 부드러운 우유 계란물에 구운 폭신 토스트 |
| **🥞 딸기 팬케이크** | 디저트 | `빵` + `계란` + `딸기` | 4초 | 생딸기가 듬뿍 올라간 달콤 팬케이크 |
| **🥛 달콤 딸기 라떼** | 음료 | `우유` + `딸기` + `물` | 3초 | 부드러운 우유와 상큼한 딸기의 만남 |
| **🍰 딸기 치즈케이크**| 디저트 | `치즈` + `우유` + `딸기` | 5초 | 진한 크림치즈와 향긋한 딸기 무스 |

## 🎲 랜덤 손님 & 주문 시스템

1. **무작위 손님 등장**: 
   - 헬로키티의 5명의 산리오 친구들(시나모롤, 마이멜로디, 쿠로미, 폼폼푸린, 포차코) 중 매 게임마다 **3명이 무작위 순서**로 찾아옵니다.
2. **랜덤 요리 주문**:
   - 8가지 요리 중 매 판 다른 조합으로 주문하여 반복 플레이에도 늘 새로운 재미를 선사합니다.
3. **캐릭터별 전용 대사**:
   - 주문할 때와 서빙 성공 시 각 캐릭터의 성격에 맞는 귀여운 맞춤 말풍선이 출력됩니다.

---

## ⏰ 핵심 게임 규칙 & 시스템

1. **60초 카운트다운 타이머 & 게이지 바**:
   - `00:60`부터 1초 단위로 부드럽게 감소 (60~31초 핑크, 30~11초 주황, 10~1초 빨강 깜빡임)
2. **요리 태우기 (5초 골든타임)**:
   - 조리 완료 후 5초 이내에 서빙하지 않으면 요리가 타버리며 `-30점` 감점
3. **점수 계산**:
   - 올바른 서빙: `+100점`
   - 빠른 서빙 보너스: 최대 `+50점`
   - 완벽 조리 보너스: `+50점`
   - 잘못된 조합 시도: `-20점`
   - 요리 태움: `-30점`
   - 0점 미만 하한선 보장
